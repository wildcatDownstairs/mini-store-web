# API 接入实施提示词

保留已有 Mini Store 的页面、视觉和动画。页面面向业务 DTO，不直接照数据库建表。对接独立 ASP.NET Core 10 / EF Core 10 后端，默认 http://127.0.0.1:5274。

删除业务 Mock 数据与本地库存/订单/金额计算。登录、客户资料、地址、商品、购物车、订单、支付记录、发货、退款、评价、库存和优惠券均通过后端接口。仅商城收藏允许保存本地 UUID 列表。

列表使用服务端筛选与分页；请求切换后旧响应不能覆盖新结果。展示加载、空结果、错误重试、提交中状态；写入失败不得显示成功。401 清理会话并引导登录；403/409 显示服务端说明。Token 不写入源码；.env.example 不含真实值。客户端隐藏权限操作只是体验，真正权限由后端决定。

价格取服务端金额，订单详情取快照，退款额度和库存扣减不在浏览器决定。报价 token 和 Idempotency-Key 要保留到请求完成，网络重试不得重复下单。只有开发环境接口允许时才展示模拟付款；页面明确“不产生扣款”。后台操作使用独立管理员账号，禁止本地切换角色伪造权限。

交叉验证路径：客户注册/地址 → 商品规格/加购 → 后端报价/下单 → 模拟付款 → 后台同一订单配货/发货/签收 → 客户评价 → 后台审核 → 商品页面可见。对金额、状态、物流和库存流水做数据库核对。后端隔离测试负责并发、权限和边界验证；浏览器验证真实页面连通性。

检查生产构建与既有测试；编写初学者可以执行的运行说明。用户已同意三个项目建立公开 GitHub 仓库，排除真实凭据、依赖目录、构建产物和本地账号文件。
